Prerequisites

Dette må være på plass før du begynner å bygge agenten. Du trenger ikke ha deployet noe på forhånd; kurset tar deg gjennom resten.

Forberedelse15–30 minutter hvis du bruker devcontainer.
MiljøCodespace eller lokal devcontainer er anbefalt.
Første målFå en grønn miljøsjekk før Lab 1.

Dette trenger du

Kryss av listen før kursdagen, eller bruk den som startpunkt når du åpner mini-nils.zip.

  • En GitHub-konto som kan opprette et privat repository.
  • Tilgang til novanet/workshop.oslo-live gjennom kursets GitHub-token.
  • En laptop der du kan åpne Codespaces eller kjøre en devcontainer, alternativt tilgang til en ferdig kursmaskin.
  • En kopi av mini-nils.zip, lastet ned og pakket ut lokalt.
  • En nettleser som kan logge inn på GitHub og Azure med kurskontoene dine.

Velg arbeidsmiljø

Devcontainer eller Codespace

Anbefalt. Starter-kitet har et ferdig miljø med .NET 10, GitHub CLI, Azure CLI, Node.js og Claude Code. Du slipper å feilsøke lokale versjoner.

Lokalt miljø

Installer .NET 10 SDK, Git, gh, Azure CLI, Node.js og Claude Code selv. Lab 2 trenger også curl og jq.

Hvis noe er blokkert

Si fra før Lab 1. Codespaces eller en kursmaskin er fallback, slik at miljøoppsett ikke spiser tiden til oppgaven.

Lag ditt GitHub-token

Tokenet brukes av workeren mot øvingsrepoet. Det er separat fra gh auth login, som du bruker med din egen GitHub-konto for å opprette agentrepoet.

1

Åpne fine-grained tokens

Gå til GitHub → New fine-grained token. Velg bare novanet/workshop.oslo-live under repository access.

2

Gi minst mulig tilgang

Velg Contents, Issues og Pull requests med read/write, og Metadata med read. Autoriser tokenet for Novanet SSO hvis GitHub ber om det.

3

Lagre verdien lokalt

cp .env.example .env
GH_TOKEN=github_pat_...

GitHub viser tokenverdien bare én gang. Ikke legg den i repository secrets, kode, issue, PR eller skjermbilde. Hvis workeren logger Resource not accessible ... (addComment), kontroller Issues write, repository access og SSO.

Miljøsjekk

Kjør dette fra mappen der du pakket ut starter-kitet. Versjonsnumrene kan være nyere, men kommandoene skal svare uten feil.

dotnet --version
git --version
gh --version
az --version
node --version
claude --version
dotnet build
FerdigDu er klar for Lab 1 når verktøyene svarer, løsningen bygger grønt og du har fått bekreftet at .env inneholder verdiene du trenger.

Ikke nødvendig før start

  • Du trenger ikke opprette Azure-ressurser selv før kurset.
  • Du trenger ikke lage en egen webhook før kurslederen har gitt deg URL og hemmelighet.
  • Du trenger ikke forstå hele workeren før Lab 1; du implementerer RunStages steg for steg.
